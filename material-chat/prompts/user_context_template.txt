#   {USER_ALIASES_NOTE}  Either empty, or a leading-space sentence listing
#                          aliases like ` They may appear in their own
#                          captured materials as: "alex", "alexk".`
#                          (Built from USER_ALIASES env var.)
# NOTE:      If USER_NAME is unset, the loader returns an empty string and
#            this template is NOT used. Edit `.env` to set the identity.
