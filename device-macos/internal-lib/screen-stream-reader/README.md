# screen-stream-reader

Python reader for frames published by the AUSM screen-stream helper
(`@ausm/device-macos-screen-stream`) through POSIX shared memory. macOS only.

This directory is the canonical source. The npm package
`@ausm/device-macos-screen-stream` ships a copy under
`python/screen-stream-reader/` (generated by `npm run sync-python`); do not
edit that copy.

## Install

```bash
pip install -e device-macos/internal-lib/screen-stream-reader   # from the repo root
# or point PYTHONPATH at this directory (what the AUSM runtime does)
```

Requires Python 3.9+ and numpy. OpenCV is optional (`pip install .[dev]`).

## Usage

```python
from screen_stream_reader import ScreenStreamConnector

connector = ScreenStreamConnector()          # /ausm-frames, /tmp/ausm-frames.sock
if connector.connect():
    frame = connector.read_frame("display-1")
    if frame:
        bgra = frame.data                    # (height, width, 4) uint8, BGRA
        print(frame.frame_number, frame.timestamp_s)
    connector.disconnect()
```

- The producer must be running and capturing (started by the AUSM runtime
  or by `ScreenStreamingService` in Node). The reader never starts capture
  on its own unless you call `start_capture()`.
- `read_frame()` / `read_all_frames()` return a private copy by default and
  verify the slot wasn't overwritten while copying. Pass `copy=False` for a
  zero-copy read-only view into shared memory; the producer may overwrite it
  at any time.
- `poll_events()` (also called automatically by `read_frame()` at most once a
  second) drains producer notifications and reopens shared memory after
  capture restarts, display changes, or a helper restart.
- `Frame.timestamp_ns` is historically misnamed: it holds **microseconds** on
  the host clock (time since boot). `timestamp_ms` also keeps its historical
  value (seconds). Prefer `timestamp_us` / `timestamp_s`.
- Event types: `EventType.CAPTURE_STARTED`, `CAPTURE_STOPPED`,
  `DISPLAY_CHANGE`, `ERROR` (`details["code"]`, e.g. `"permission_denied"`).

The binary layout is specified in `device-macos/screen-stream/README.md`.

## Tests

```bash
python3 -m unittest discover -s tests
```

The tests create private shared memory segments; they do not need Screen
Recording permission.
