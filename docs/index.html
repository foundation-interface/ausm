      Materials
      
      
      A material is one thing you look at: a tab, a file, a thread.
      

      
      One title in one app, one id
      
      
      Switch tabs, or open the same tab in a second window.
      
      
      
        
      
          
      
            
      
              
      
              
      
            
      
            
      
              
      
            
      
          
      
          
      
            
      
              
      title

      window_id4182
      
              
      material_id…
      
            
      
            
      mat_ + sha256(title + "\0" + bundle_id)[0:12]
      
            
      
          
      
        
      
        
      The window id changes. The material id doesn't. It's the real hash, computed here.
      
      
      

      
      Frames are kept only when the window changes

      Concept 04
      
      
      Tasks
      
      
      Detectors are plain-language rules a model checks against the screen. One of them names your task.
      

      
      
        
      
          
      
            
            
          
      
          
      
          
      
          
      
          
      
          
      
          
      
            
            
          
      
        
      
        
      
      
      

      
      How a task keeps its id
      
      
      The model only returns a label. The tracker decides if it's the same work.
      
      
      
        
      
          
      
            
      Model says
      
            
      
            
      
          
      
          
      
            
      Tracker
      
            
      Current taskNone
      
            
      
            
        
          
        
        
        
        
        Same work = label words overlap ≥ 70% and description ≥ 60%. This runs the real rule.
